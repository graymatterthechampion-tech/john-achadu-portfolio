About

I build tools that
do one job properly.

I'm a software developer in Lagos, completing GoMyCode's Full-Stack Software Engineering track in October 2026.

My first production system is an email pipeline. BulkMail sends campaigns from authenticated accounts with managed sending addresses, backed by PostgreSQL on Neon and deployed on Render. Its companion verifier, built with React and Express, cleans contact lists before anything is sent.

I'm now building a search engine API from scratch in TypeScript: a web crawler, an inverted index and BM25 relevance ranking, served behind API keys so my other apps can use it. I'm currently collaborating on the development of a social media app (in progress).
